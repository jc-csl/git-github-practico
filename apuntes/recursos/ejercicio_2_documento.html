Estación meteorológica del aula

Proyecto de 1º de Bachillerato para medir la temperatura, la humedad y la presión del patio y publicar los datos en una web. El código está en GitHub: ver repositorio.

Aviso: los sensores funcionan a 3,3 V. Conectarlos a 5 V puede dañarlos.

Componentes

ComponenteCantidadPrecio aprox.
Placa ESP3218,50 €
Sensor BME28014,20 €
Cables dupont101,00 €

Instalación

  1. Clona el repositorio.
  2. Abre la carpeta en VS Code.
  3. Sube el programa estacion.ino a la placa.
git clone https://github.com/usuario/estacion-meteo.git
cd estacion-meteo

Estado del proyecto

  • Montar el circuito
  • Leer la temperatura
  • Guardar los datos en el archivo datos.csv
  • Publicar la web con GitHub Pages

Descartado: usar un sensor DHT11 (sustituido por el BME280, más preciso).
