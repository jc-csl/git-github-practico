# Ejercicio Guiado 2: Dominando el Editor Markdown

Este ejercicio está diseñado para que pongas a prueba todas las funcionalidades del **Editor Markdown de vista dividida** que creamos anteriormente.

## Objetivo
Redactar un documento enriquecido utilizando atajos de teclado y herramientas de formato.

---

## Paso 1: Estructura básica
Abre el editor (`index.html`) y escribe los siguientes encabezados (puedes usar los botones de la barra superior `H1`, `H2` o teclear `#`):

```markdown
# Guía de mi Proyecto
## Tareas Pendientes
## Base de Datos
```

## Paso 2: Listas de tareas
Debajo de `## Tareas Pendientes`, crea una lista interactiva usando el botón de **Tarea** de la barra (o tecleando `- [ ]`):

```markdown
- [x] Configurar repositorio
- [ ] Escribir documentación
- [ ] Subir a GitHub Pages
```

## Paso 3: Inserción de imágenes
Ve al final del documento y usa el atajo `Ctrl + Shift + I`.
1. En el cuadro que se abre, arrastra una imagen desde tu ordenador.
2. Selecciona **Ruta relativa (GitHub Pages)**.
3. Haz clic en **Insertar imagen**.
4. *Opcional:* Haz clic en el botón "Guardar imagen en disco" del modal para descargarla en tu carpeta local `img/`.

## Paso 4: Código y Tablas
Debajo de `## Base de Datos`, inserta un bloque de código y una tabla:

1. Pulsa el botón **Bloque de código** y reemplaza el texto interno.
2. Pulsa el botón **Tabla** y llena un par de datos de ejemplo.

## Paso 5: El Índice automático
Coloca el cursor justo debajo del título principal (`# Guía de mi Proyecto`).
Pulsa el botón **Índice** en la barra superior. Verás cómo se autogenera una lista con enlaces funcionales a cada sección de tu documento.
