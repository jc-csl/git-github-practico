Git y GitHub en la práctica

Todo el curso en un solo repositorio: un laboratorio con terminal simulada, ejercicios por situaciones y soluciones; apuntes en Markdown con ejercicios guiados para tu terminal real; y un editor Markdown para escribir tu propia documentación.

Centro San Luis · curso 2026-27 · Juan Carlos San Román

Declaración de uso de IA · Guía de uso de la IA en el aula, Centro San Luis (nivel verde). Este material parte de los apuntes propios del profesorado (resúmenes de comandos Git y taller Git/GitHub); se ha utilizado IA para la redacción de los ejercicios, el formateo, el simulador y la comprobación de los comandos en una terminal real, con revisión y validación del profesorado.

  • Cada ejercicio arranca con su escenario preparado
  • Comprobar corrige tu trabajo; Solución la muestra completa

Cómo estudiar cada tema

  1. Lee la teoríaLa sección de la chuleta o del resumen completo.
  2. Practica sin riesgoEl ejercicio del laboratorio: si algo se rompe, Reiniciar.
  3. Hazlo de verdadEl ejercicio guiado de los apuntes, en Git Bash o en la terminal de Linux.
  4. CompruebaCon Comprobar en el laboratorio y las soluciones desplegables de los apuntes.

El orden recomendado de los temas está en el itinerario de los apuntes. Al final, los retos finales sirven de evaluación.

Estructura del repositorio

git-github-practico/
├── index.html      ← esta portada
├── laboratorio/    ← web de ejercicios + terminal simulada
│   ├── index.html
│   ├── lab.js       (simulador y comprobaciones)
│   └── lab.test.js  (node lab.test.js)
├── apuntes/        ← Markdown: chuleta, resumen,
│   │                 ejercicios guiados, retos
│   └── recursos/    (PDF, scripts, soluciones)
├── editor/         ← editor Markdown
└── imagenes/       ← imágenes compartidas

Usarlo en tu equipo

git clone https://github.com/jc-csl/git-github-practico.git
cd git-github-practico
# Abre index.html con doble clic.
# El laboratorio funciona sin conexión;
# el editor necesita internet para cargar
# sus librerías (marked y DOMPurify).

Las tres partes son independientes: el laboratorio no necesita el editor ni los apuntes, y al revés. Lo que las une son los enlaces cruzados entre cada ejercicio de los apuntes y su laboratorio.
